# 记忆场景与事实边界

三个场景已经实现在 `index.html` 中。它们是可回访的风格化沙盘，不是实测户型，也不是对真实街区的精确复刻。

## 香港：城市海滨酒店

用户指定地点：香港嘉里酒店。

用户确认的空间特征：高层海景、现代高密度酒店。

当前用抬升的客房剖面、面向海港的大窗、密集酒店立面与滨水城市楼群表达这些特征。地面海滨步道与客房分开。酒店立面的楼层带采用压缩示意，不表示实际入住楼层或酒店真实层数。

具体楼层数字、真实房型、门窗尺寸、家具和邻楼排列尚未提供，采用简化创作布局；海港意象不是对实际窗景的逐楼复刻。公开原型不展示具体入住日期。

### 香港城市背景参考

背景按“红磡湾的酒店与步道 → 维多利亚港水面 → 港岛城市海岸 → 后方山脊”的关系进行风格化压缩。参考材料：

- [嘉里酒店官方介绍](https://www.shangri-la.com/hongkong/kerry/about/)：酒店位于九龙红磡湾的城市海滨。
- [嘉里酒店官方交通与地图](https://www.shangri-la.com/hongkong/kerry/about/map-directions/)：用于理解酒店与港湾周边的相对位置。
- [香港旅游发展局：维多利亚港](https://www.discoverhongkong.com/eng/explore/attractions/victoria-harbour.html)：参考港湾两岸的城市天际线。

场景设有 12 栋沿岸塔楼、10 栋中景塔楼、8 栋后排楼宇及 12 组裙房。商业高楼采用竖向幕墙、退台冠部或八角锥顶；住宅塔楼采用密排窗格和较平的屋顶。海岸曲线、楼群高度与山脊共同形成前后层次，部分窗户随房间昼夜明暗变化。

街区布局、塔楼轮廓、楼高和色彩均为创作取舍；这里表达高密度海滨城市的尺度与节奏，不对应精确地图、真实地标模型、实际窗景或入住朝向。资料页面与场景在 2026-10-22 核对及更新。

## 共用风格与行为

所有场景使用连续噪声地形、三阶卡通光照、反向外壳描边与正交斜俯视。圆角建筑和低多边形植物服务于记忆沙盘，不使用体素方块。

住户姓名、作息、互动和手记均为虚构脚本。多人会错开部分活动时刻，并通过预设路点往返个人与公共区域；没有接入 LLM，也没有通用自动寻路。每个地点独立保存时间、种子、回访次数、最近手记与记忆状态。

## 记忆物件与个人留言

每处房间各有三件可以打开的物品：香港的房卡、行李箱与纸杯，都灵的钥匙串、便笺与茶杯，宿舍的课程表、暖水杯与阳台衣物。

这些物件、对应短故事以及按时段出现的生活片段均为原型创作，不是经用户确认的真实物品或经历。房间中的位置变化由脚本驱动，也不表示接入了自主生活的模型 Agent。

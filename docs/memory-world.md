# 还住在这里：记忆世界融合版

2026-10-24 更新为低多边形音乐星球：沿球面步道随音乐行走，经过香港海港、都灵红瓦街巷和松江校园，再进入原来的三个微缩房间。城市小景采用记忆意象布局，不使用真实经纬度。

## 0.5.0：以房间为基准统一建模

外部地形改为连续的三角切面球体；建筑使用圆角挤出、窗带、拱廊和斜屋顶，树木、云朵、渡轮和阿绵也改成同一套低多边形造型。三阶卡通光照、鼠尾草绿、米色、陶土色和柔和轮廓来自房间。补光让南侧城市也能读清细节；入口移到房子前方，避免挡住窗面。

音乐波纹不再按体素高度跳变。GPU 地形、阴影深度与物体球面锚点使用相同的连续公式，球面两极与经线接缝保持连续。步道完整保留平面高度，阿绵迈步不会被波纹顶起。减少动态与节能设置继续生效，原有房间和个人记忆不迁移、不改写。

## 0.4.0：统一界面与过渡

星球、城市、房间、记忆编辑、记忆册、设置与播放器共用 `public/theme.css` 的暖白、鼠尾草绿与陶土色。房间的地表、材质、标签、工具条和城市预览图同时调整；原来的空间布局、住户和个人记录继续沿用。

城市不再平排在上半球。香港位于北侧、都灵位于中段、上海位于南侧，斜向步道连接它们。停靠点与新步道同步，接近城市和跟随旅人时镜头会按城市所在纬度调整。小屏城市标签避开视角控制条；支持拖动、滚轮、双指缩放与键盘。

星球与城市之间保留同一个场景，以镜头缓动和卡片淡入衔接。进入或离开房间时使用短暂的暖色过渡，等待新场景就绪后展开；后发导航会取消旧请求。记忆册、设置与编辑窗共享淡入淡出，Esc 与关闭按钮行为一致，嵌套编辑退出后回到原物件。房间的每秒生活更新只修改文字，避免刷新整排按钮造成焦点丢失。

减少动态模式同时覆盖页面过渡、镜头与房间装饰动画，并遵循系统的减少动态偏好。预览素材通过 `scripts/room-preview.html` 在独立示例状态下生成，没有读取个人记忆或修改用户的房间时间。

## 使用

研究目录中双击 `启动研究台.cmd`，打开 <http://127.0.0.1:4171/>。运行期间只监听本机；没有上传或云同步。保持同一浏览器、主机名和端口，以读取同一份存档。

1. 拖动星球、点击悬浮城市名或底部城市入口，可以走近城市。点击房间建筑的绿色门牌或左侧房间按钮即可进入。房间侧边返回城市，左上角返回星球，右上角可以回到上次房间。浏览器前进、返回也可以使用。
2. 点击“跟着音乐出发”，跟随阿绵沿步道前进。到每座城前会短暂停步，右上角出现房间入口；由你决定是否进入，不会自动切走。暂停会停下脚步，拖动进度会移动旅人，房间生活继续。右侧脚印按钮重新跟随旅人，总览按钮查看整颗星球。设置中可选择本机音频并调整三城的行走顺序。
3. 房间内点击物件，写自己的名字、故事、留言，最多添加 12 张照片。照片最长边缩至 1600 像素并重新编码，不保存原始照片元数据。单张原图限 20 MB。
4. 记忆册分为“我的物件”“这里的生活”“停留的日子”。真实日期支持未知、月份、日期和多次停留；没有填日期时保持空白。
5. 设置中的“导出完整备份”把文字、房间状态、照片、所选音乐保存到一个 JSON 文件。“恢复备份”先检查文件并展示内容数量；恢复后可以回到导入前的版本。定期导出，尤其在清理浏览器或换设备之前。

音乐支持浏览器能解码的常见格式，文件限 40 MB，时长 5 秒至 20 分钟。默认 64 秒音轨为程序合成演示，不代表个人经历的配乐。默认观看顺序为香港、都灵、上海，可以调整，**不宣称这是人生真实先后**。

## 三个时间与生活规则

人生日期只用于记录；音乐时间决定回访停靠点和环境响应；生活时间控制需求、日夜和行为。音乐暂停或拖动不会回滚房间生活。房间的时间滑块会暂停该房间的自动时间，方便看清一个时刻；“让生活继续”可以恢复。

每 40 秒现实时间推进 1 个模拟小时。精力、饱腹、陪伴和整理需求参与行动选择；室友傍晚聚在共享空间，宿舍住户依次使用公共洗漱位置。关闭网页后没有后台进程，下次打开时最多补算 48 个模拟小时。每 6 个模拟小时至多记一件小事，事件稳定编号并去重，每个房间保留最近 40 条。

创作引子、旧项目创作、程序模拟与用户自己写的记忆分别显示。住户采用有限状态规则，不使用语言模型；场景是风格化示意，不是实景扫描。当前有固定的三个城市和三个房间，新增地点模型仍属后续扩展。

## 实现

| 文件 | 职责 |
| --- | --- |
| `app.html`、`styles.css`、`src/app.js` | 地点路由、界面、统一存档与音乐时钟 |
| `public/theme.css`、`public/room-theme.css` | 全应用共享视觉变量与房间内的界面样式 |
| `src/motion.js`、`src/navigation.js` | 过渡动画、减少动态与异步导航取消 |
| `src/scene/music-planet.js`、`planet-kit.js`、`miniature.js` | 倒角建筑、低多边形植物与旅人、共用卡通材质、跟随与自由镜头、房间入口、资源生命周期 |
| `src/scene/soft-planet.js`、`surface-wave.js` | 连续切面球体、连续音乐波纹、同步阴影与物体贴地、完整球面步道 |
| `public/planet/engine/` | 原版参考代码保留；运行时使用噪声/布局、球面放置、气候，以及 voxelmodel 中的球面坐标工具，不再构建体素模型 |
| `public/planet/js/`、`src/journey.js` | 意象布局、地形配色、天色章节，以及由音频时钟决定的连续行程 |
| `public/room/index.html` | 适配后的原有房间；以同源 iframe 隔离，接收宿主生活状态与音乐特征 |
| `src/data.js`、`src/model.js` | 稳定实体 ID、日期精度、数据验证、旧存档迁移、旅程段落 |
| `src/life.js` | 需求与行为、有限离线补算、事件去重 |
| `src/music.js` | 单一 AudioContext / 音源管理、暂停恢复和进度 |
| `public/vendor/planet-audio.js` | Voxel Beat Planet 的离线 FFT 与节拍分析 |
| `src/storage.js` | localStorage 元数据、IndexedDB 媒体、完整备份与恢复 |
| `scripts/build.mjs` | 语法检查并打包到 `dist/`，无需安装 npm 依赖 |

音乐星球原版引擎文件保留不改，以现有 Three.js r160 提供 THREE 接口；当前球体、模型、连续波纹、光照、行程和镜头由本项目实现。同一时间只有星球或一个房间在渲染。星球卸载时取消 RAF、监听与 ResizeObserver，并释放几何体、材质、深度材质、纹理、阴影贴图和 renderer；房间卸载时保存姿态、停止 RAF 并释放 renderer，移除整个 iframe。切换期间音乐实例持续复用。

当前城市为三组可识别的微缩小景，包含香港高楼与渡轮、都灵尖塔与拱廊公寓、上海东方明珠意象与松江 30 号宿舍及校园门口。室内沿用原项目，进入时切换场景，不是穿过一扇真实几何门的连续运镜。减少动态效果关闭星球波纹、步态和自动跟随；节能画质降低渲染像素密度。

## 存档

元数据键为 `room-of-memories-world-v1`；媒体库为 `room-of-memories-media` / `assets`。原有 `room-of-memories-v3` 首次迁移前原样保存在 `room-of-memories-v3-before-world`，设置中可导出。迁移失败不会覆盖旧存档。

完整备份格式为 `format: room-of-memories, version: 1`，包括 world 和内联 assets。只导出仍被引用的媒体。恢复先验证结构、日期、引用与 MIME 类型，拒绝远程媒体 URL，媒体总量限 100 MB。照片还会实际解码校验。恢复时为媒体分配新 ID，保留导入前快照及旧媒体，确保撤回不引用被覆盖的数据。恢复后从保存的生活时刻继续，不立即补算备份存放期间的时间。

## 验证

运行 `npm.cmd test` 检查迁移、暂停生活、补算上限、事件去重、共享洗漱位置、日期、备份引用、三种时间隔离、音源暂停恢复和 seek。运行 `npm.cmd run build` 检查全部模块及嵌入式房间脚本语法。

在地址后加 `?debug`，设置中显示实际活动画布、renderer 资源数量、音乐实例和运行错误，供重复切换检查。该面板不显示记忆正文。

外层研究目录的 `evidence/` 保存本轮浏览器实测记录。测试恢复使用 `localhost:4171` 作为独立的浏览器来源，与日常的 `127.0.0.1:4171` 存储隔离。它验证备份不依赖原站点存储，并不代表覆盖了所有浏览器或设备。

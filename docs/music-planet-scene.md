# 回去的路：音乐星球

2026-10-24 / 0.5.0。以原有房间为视觉基准，保留音乐星球的体验结构：阿绵随节奏走过不同城市，再从城市进入记忆房间。外部世界使用连续切面地形、倒角建筑、低多边形植物与云朵，不再使用小方块堆叠的外观。

香港是连续窗带的海景酒店、层叠高楼与渡轮；都灵是陶土红瓦、真正留空的拱廊与八角尖塔；上海保留珍珠塔意象、松江校门、30 号宿舍的阳台与晾晒。阿绵的头、四肢和衣服改为多面球体与圆柱，交替步态仍由音乐节拍控制。

三阶卡通光照与房间使用相同的 104 / 184 / 255 梯度。鼠尾草绿、米色、陶土色来自现有房间材质；模型有细轮廓、柔和阴影。面向镜头的漫射补光照顾背光的南侧城市，房间入口位于建筑前方，避免遮住窗面。

球体采用 20,480 个三角面，地形与城市共用同一个高度采样器。波纹根据参考项目的传播波重新实现为连续位移，并减小频率与幅度；纬度权重消除球面两极的奇点。着色器、阴影深度和 CPU 物体锚点共享常量与公式，建筑、植物随地面起伏，步道维持固定高度。树、路灯、踏步实例化，每栋建筑合并主体和窗面。

城市保持不规则高低分布：香港纬度 .95 弧度、都灵 .33、上海 -.40。坐标属于记忆意象，不是真实地理位置；斜向环路经过城市门前，背面有树林、湖泊与田野。public/planet/js/scene-manifest.js 是布局唯一来源。抵达城市会短暂停步，进入房间仍由用户选择。

内置 64 秒程序合成演示曲；0 / 22 / 42 / 56 秒是人工编排的天色节点。可替换本机音乐，继续使用相同的音频分析与播放实例。拖动进度、暂停、跟随、自由旋转都保留。房间里的生活时钟独立于音乐时间。

同一时间只展示一个 WebGL 场景。切换时释放星球几何体、材质、纹理、阴影与渲染器；返回后按音乐进度恢复旅人位置。减少动态关闭波纹、步态、云与自动跟随；节能关闭阴影与外部细描边。内外模型统一不需要改写房间存档。

19 项自动检查覆盖原有数据、音乐、导航，以及新增连续波纹的有限值、跨经线与两极连续性、无体素跳变、整条步道平稳贴地。十二类新模型的有限顶点和尺寸边界另有构建后检查。浏览器截图与交互验证记录见研究目录 evidence/miniature-*。
